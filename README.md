HARD REQUIREMENTS:
This mod requires the following:
1, The Latest version of Harmony
2, AI Influence version 6.0.2
3, Bellum Civile version 1.2.7
4, Bannerlord version 1.4.5

Installation instructions

1, Install and enable the required mods listed above.
2, Extract the downloaded archive.
3, Make sure you go into the parent folder's properties and unblock it.
4, Copy the BellumAIEventBridge folder from inside the archive’s Modules folder into your Bannerlord installation’s Modules folder.
5, Confirm the resulting structure is: Mount & Blade II Bannerlord\Modules\BellumAIEventBridge\SubModule.xml
6, Enable Bellum AI Event Bridge in the launcher. Place it below both Bellum Civile and AI Influence, with Harmony loading before all.
Launch the game and load your campaign. A startup notification displays the status of the character and dynamic-event integrations.

Once in game:
wait for Bellum Civile to catalog an event  (any event that appears to you as a notification will do) then talk to an NPC or wait for a dynamic event to be generated.

Notes:
Source code is in the "Sources" folder next to the modules. It does not need to be installed alongside modules. It's simply a modder's resource.
